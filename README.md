# Hotel Restaurant Website

This is a simple full-stack website for a hotel restaurant, built with React, Vite, Tailwind CSS on the frontend, and Node.js with Express and TypeScript on the backend.

## Features

**Frontend:**
*   Home page
*   Menu page (fetches data from backend)
*   Reservations page (submits data to backend)
*   Contact page
*   Responsive design
*   Client-side routing

**Backend:**
*   REST API for menu items and reservations
*   Uses JSON files for mock data persistence
*   CORS enabled for frontend interaction
